# Arena of the Immortals

Playable MVP of a turn-based 3v3 strategy battle set in the world of Aethera.

**Play it:** https://blockgeneral.github.io/arena-of-the-immortals/

This is an early prototype. You can battle the AI opponent, or duel a friend: press Play, choose Private duel, and send them the invite link. Sections marked "Coming soon" are previews of what is planned. It plays in landscape, on a desktop or a phone.

Private duels are meant for friends: this early version is not protected against cheating.

New here? Press Play, then Tutorial. On a phone you can add the page to your home screen and it opens full screen like an app.

This repository holds only the built game. It is replaced whenever a new build is published.
