# Arena of the Immortals

Playable MVP of a turn-based 3v3 strategy battle set in the world of Aethera.

**Play it:** https://blockgeneral.github.io/arena-of-the-immortals/

This is an early prototype. Battles against the AI opponent work. Sections marked "Coming soon" are previews of what is planned. It plays in landscape, on a desktop or a phone.

This repository holds only the built page (`index.html`). It is replaced whenever a new build is published.
